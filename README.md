# Skills

A collection of Claude skills ready for sharing on GitHub.

## Structure

Each skill lives in its own subdirectory containing a `SKILL.md` file (with YAML frontmatter: `name`, `description`) plus any supporting scripts or references.

```
github-skills/
├── README.md
└── <skill-name>/
    └── SKILL.md
```

## Adding a skill

Create a new folder named after the skill and add a `SKILL.md` inside it.
